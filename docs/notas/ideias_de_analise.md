# Ideias de Analise

Este arquivo consolida ideias iniciais de analise para o estudo de caso com o dataset de consumo residencial. As propostas abaixo ainda sao exploratorias e precisam ser refinadas metodologicamente antes de entrar no texto final do PFC.

## Eixos iniciais

- identificar horarios de maior consumo;
- identificar horarios de menor consumo;
- caracterizar faixas de consumo intermediario;
- comparar comportamento de consumo entre dia e noite;
- investigar padroes de uso ao longo do tempo;
- observar possiveis horarios de pico;
- levantar hipoteses sobre equipamentos de maior impacto energetico nos periodos de pico.

## Hipoteses de interpretacao

- horarios de pico podem estar relacionados a momentos de maior ocupacao da residencia;
- determinados padroes podem refletir atividades domesticas recorrentes;
- submetragens podem ajudar a inferir tipos de uso energetico;
- o contexto temporal pode apoiar explicacoes tecnicas mais interpretaveis.

## Cuidados metodologicos

- o dataset representa uma residencia especifica, entao nao deve ser generalizado para qualquer edificacao;
- nao ha, nesta base, contexto externo suficiente para afirmar causa de comportamento;
- inferencias sobre equipamentos devem ser tratadas como hipotese, nao como conclusao;
- interpretacoes futuras por LLM devem ser ancoradas em indicadores calculados e limitacoes explicitadas.
